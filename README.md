# 🚀 منصة المس أمل شفيق السيد (Miss-Amal-Platform)

منصة تعليمية تفاعلية متكاملة مخصصة لتدريس **البرمجة وعلوم الذكاء الاصطناعي** لطلاب المرحلتين الثانوية، مع لوحة تحكم كاملة لإدارة الطلاب، ونظام مصادقة، ومنتدى تفاعلي، ومحرر أكواد برمجي مباشر.

---

## ✨ مميزات المنصة
* 🧠 **قسم الذكاء الاصطناعي:** شرح ومقالات ومشاريع عملية في تقنيات الذكاء الاصطناعي وتعلم الآلة.
* 💻 **محرر الأكواد التفاعلي:** مححر مدمج لتجربة وتشغيل شفرات الـ JavaScript مباشرة داخل المتصفح.
* 👥 **مجتمع الطلاب (المنتدى):** مساحة تفاعلية لتبادل الأسئلة، النقاشات، ورفع الصور والمشاريع.
* 📚 **مكتبة المذكرات:** تحميل الكتب والملخصات الدراسية مقسمة حسب الصف الدراسي.
* 🛡️ **لوحة تحكم الأدمن (للمعلمة):** إدارة الطلبات المعلقة، قبول وحذف الطلاب، نشر الإشعارات ولوحة الشرف.
* ☁️ **قاعدة البيانات (Supabase):** ربط المنصة سحابياً لضمان حفظ بيانات المستخدمين بأمان.

---

## 🛠️ التقنيات المستخدمة
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **UI Framework:** Bootstrap 5 (RTL Support) & FontAwesome Icons
* **Database & Backend:** Supabase
* **Deployment:** GitHub Pages / GitHub Repositories
