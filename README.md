# منصة المس أمل شفيق السيد للبرمجة والذكاء الاصطناعي

منصة تعليمية تفاعلية متكاملة مخصصة لطلاب المرحلة الثانوية، تجمع بين المحتوى التعليمي المنظم، التفاعل المباشر، ومحركات تشغيل الأكواد البرمجية في بيئة سحابية سريعة وعصرية.

---

## المميزات الرئيسية

* **واجهة مستخدم عصرية (Liquid Glassmorphism):** تصميم زجاجي خفيف وسريع الاستجابة يدعم الوضع الليلي (Dark Mode) والنهاري (Light Mode) بسلاسة تامة على جميع الشاشات والهواتف.
* **محررات أكواد تفاعلية مدمجة:**
  * محرر ومنفذ لأكواد **Python**.
  * محرر ومنفذ لأكواد **JavaScript** مع وحدة تحكم (Console) مدمجة.
  * محرر **HTML & CSS** مع معاينة حية ومباشرة للتصميم.
* **مكتبة تعليمية شاملة:**
  * قسم خاص بالكتب والمذكرات الدراسية مصنفة حسب الصف الدراسي مع خاصية البحث السريع.
  * قسم للفيديوهات التعليمية والشروحات المرئية.
  * قسم للمنصات التعليمية المعتمدة.
  * قسم للامتحانات والاختبارات التفاعلية.
* **منتدى نقاش مباشر (Real-time Chat):** تواصل فوري بين الطلاب والمعلمة مع دعم إرسال الصور، وتعديل أو حذف الرسائل.
* **لوحة تحكم متكاملة للمشرف (Admin Dashboard):**
  * مراجعة وتفعيل أو رفض طلبات انضمام الطلاب الجدد.
  * إدارة كاملة للمحتوى (إضافة وحذف الإشعارات، الكتب، الفيديوهات، المنصات، الامتحانات، ولوحة الشرف).
  * نظام **سجلات التدقيق (Audit Logs)** لتتبع كافة العمليات والتحديثات التي تتم على المنصة تلقائياً.

---

## التقنيات المستخدمة

* **الواجهة الأمامية (Front-End):** HTML5, CSS3, Vanilla JavaScript (ES6+), Bootstrap 5 (RTL), FontAwesome.
* **قاعدة البيانات والخدمات السحابية (Back-End as a Service):** Supabase.

---

## هيكل قاعدة البيانات (Supabase Tables)

تعتمد المنصة على الجداول التالية في قاعدة البيانات:
* `profiles`: بيانات الطلاب والمعلمين وحالة تفعيل الحسابات.
* `admins`: بيانات حسابات المشرفين.
* `notifications`: الإشعارات والتنبيهات العامة.
* `honor_students`: بيانات وصور الطلاب المتميزين في لوحة الشرف.
* `books`: المذكرات والكتب الدراسية.
* `educational_videos`: روابط وعناوين الفيديوهات التعليمية.
* `platforms`: روابط وعناوين المنصات التعليمية.
* `exams`: روابط وعناوين الامتحانات والاختبارات.
* `chat_messages`: رسائل وصور منتدى النقاش المباشر.
* `audit_logs`: سجل الأحداث والنشاطات الإدارية.
