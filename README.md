🚀 منصة المس أمل شفيق السيد للبرمجة والذكاء الاصطناعي
​منصة تعليمية تفاعلية متكاملة مخصصة لتعليم البرمجة والذكاء الاصطناعي للمرحلة الثانوية، مصممة بواجهة عصرية خفيفة وسريعة بنمط Liquid Glassmorphism مع دعم كامل للوضع الليلي والنهاري وتجاوب تام مع جميع الشاشات.
​✨ أبرز المميزات (Features)
​🎨 تصميم عصري وسريع (Optimized Liquid Glassmorphism): واجهة زجاجية انسيابية خفيفة على المتصفح لضمان أعلى سرعة تحميل وأداء بدون أي تهنيج، مع إمكانية التبديل السلس بين الوضع النهاري (Light Mode) والوضع الليلي (Dark Mode).
​💻 محررات أكواد تفاعلية مدمجة (Live Code Editors):
​محرر ومُنفذ أكواد Python المباشر.
​محرر ومُنفذ أكواد JavaScript مع شاشة Console.
​محرر HTML & CSS مع معاينة حية فورية (Live Preview).
​📚 مكتبة رقمية شاملة:
​قسم الكتب والملخصات مع ميزة البحث السريع وتصفية المحتوى حسب الصف الدراسي.
​قسم الفيديوهات التعليمية لعرض الشروحات المرئية.
​قسم المنصات التعليمية لتجميع أهم المنصات والمصادر المعتمدة للطلاب.
​قسم الامتحانات والاختبارات لتقييم مستوى الطلاب بشكل دوري.
​💬 منتدى نقاش تفاعلي مباشر (Real-time Chat): غرفة محادثة تجمع الطلاب والمعلمة مع إمكانية إرسال الصور، وتعديل أو حذف الرسائل.
​🏆 لوحة الشرف والإشعارات: عرض الطلاب المتميزين وإنجازاتهم، بالإضافة إلى نظام إشعارات وتنبيهات فوري.
​🛡️ لوحة تحكم متكاملة للأدمن (Admin Dashboard):
​إدارة طلبات انضمام الطلاب الجدد (قبول / رفض).
​إدارة المحتوى بالكامل (إضافة وحذف الكتب، الفيديوهات، المنصات، الامتحانات، الإشعارات، ولوحة الشرف).
​سجلات التدقيق (Audit Logs): متابعة وتسجيل كافة الأنشطة والأحداث داخل المنصة تلقائياً.
​🛠️ التقنيات المستخدمة (Tech Stack)
​الواجهة الأمامية (Frontend): HTML5, CSS3 (Custom Variables & Glassmorphism), JavaScript (ES6+).
​التنسيق والتجاوب (UI Framework): Bootstrap 5.3 (RTL), Font Awesome 6.4, Google Fonts (Readex Pro).
​قاعدة البيانات والخدمات السحابية (Backend & Database): Supabase (PostgreSQL).
​🗄️ هيكل جداول قاعدة البيانات (Supabase Schema)
​تعتمد المنصة في عملها السحابي على الجداول التالية:
​profiles: لحفظ بيانات الطلاب والمعلمين (id, name, username, role, grade, phone, parent_phone, pass, status).
​admins: لحفظ بيانات المشرفين (id, name, phone, password).
​notifications: للإشعارات والأخبار (id, title, content, created_at).
​honor_students: للطلاب المتميزين (id, name, achievement, image_url).
​books: للمذكرات والكتب (id, title, grade, url).
​educational_videos: للفيديوهات التعليمية (id, title, url).
​platforms: للمنصات التعليمية (id, title, url).
​exams: للامتحانات والاختبارات (id, title, url).
​chat_messages: لرسائل المنتدى (id, sender, content, image_url).
​audit_logs: لسجلات النشاط والتدقيق (id, action, created_at).
